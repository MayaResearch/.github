# Maya Research

Voice models for real-time conversations. Integrate Maya into your voice agent with our public cookbook, examples and API guides.

**[Website](https://www.mayaresearch.ai/) · [Cookbook](https://github.com/MayaResearch/maya-cookbook) · [API docs](https://github.com/MayaResearch/maya-cookbook/tree/main/docs/api-reference) · [Voices & languages](https://github.com/MayaResearch/maya-cookbook/blob/main/docs/speakers.md)**

## Integrate Maya

Choose your framework. Give the linked page to your coding agent and say **“Integrate Maya TTS into my app.”** Each page starts with a ready-to-copy prompt, followed by setup and testing instructions.

### [Maya + LiveKit →](https://github.com/MayaResearch/maya-cookbook/blob/main/integrations/livekit/README.md)

Add Maya speech to your LiveKit agent.

### [Maya + Pipecat →](https://github.com/MayaResearch/maya-cookbook/blob/main/integrations/pipecat/README.md)

Add Maya speech to your Pipecat pipeline.

Keep your existing speech recognition, LLM and transport. Change only text to speech. The guides also include optional complete demos if you are starting from scratch.

## Building with a coding agent?

Share an integration link above, or give your agent the [cookbook](https://github.com/MayaResearch/maya-cookbook) and ask:

> Read AGENTS.md and choose the smallest example for my app. Preserve my existing stack and files. Follow the example's pinned dependencies. Run keyless checks first and ask before paid API calls, microphone use or deployment. Never put keys in chat, source code or browser code. Tell me what passed and what still needs testing.

## Models and documentation

The cookbook currently includes **Maya Calyx** examples. Maya Research is the home for our voice models; check the [speaker guide](https://github.com/MayaResearch/maya-cookbook/blob/main/docs/speakers.md) for the documented voice and language coverage, and each integration guide for compatibility.

The cookbook is a **public beta** with pinned examples—not a guarantee for every production environment. [See what has been tested](https://github.com/MayaResearch/maya-cookbook/blob/main/docs/validation.md) and the [production checklist](https://github.com/MayaResearch/maya-cookbook/blob/main/docs/production-checklist.md).
